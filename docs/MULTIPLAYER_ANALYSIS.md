# Анализ: Мультиплеер для ALGOKOSMOS игр

## Методология оценки

| Критерий | Вес | Описание |
|----------|-----|----------|
| **Потенциал мультиплеера** | 30% | Насколько игра становится лучше в 2+ игроков |
| **Техническая сложность** | 25% | Насколько сложно реализовать online |
| **Задержка (latency)** | 20% | Чувствительность к пингу |
| **Веселье в мультиплеере** | 15% | Насколько интересно играть вместе |
| **Монетизация** | 10% | Потенциал для премиум-фич |

## Рекомендация

**Делать онлайн:**
1. **Tetris Battle** — максимальный потенциал, низкая сложность
2. **Pong Online** — уже готов к мультиплееру
3. **Snake Arena** — проверенная модель (Slither.io)

**Не делать онлайн:**
- Space Invaders — локальный кооп лучше
- Arkanoid — дубликат Breakout
