# ALGOKOSMOS.COM — Гайд по бренду

## Миссия

Создавать и распространять игры под единым брендом, начиная от классических ретро (Dendy, ZX Spectrum) до современных Three.js шутеров.

## Логотип

**Название:** ALGOKOSMOS.COM

**Стиль:** Космос + математика + ретро

**Цвета:**
- Основной: #8844ff (фиолетовый)
- Акцент: #00ffff (голубой)
- Фон: #0a0a1a (тёмный космос)

## Интеграция в игры

1. **Заставка:** Логотип ALGOKOSMOS.COM при запуске
2. **HUD:** Watermark в интерфейсе
3. **Кредиты:** Упоминание в конце игры
4. **README:** Описание бренда в каждом репозитории

## Платформы

- Web (все браузеры)
- Mobile (PWA)
- Desktop (Electron)
