# ALGOKOSMOS.COM Games

**Бренд:** ALGOKOSMOS.COM — открытая платформа игр с открытым исходным кодом.

## Миссия

Создавать и распространять игры под единым брендом, начиная от классических ретро (Dendy, ZX Spectrum) до современных Three.js шутеров. Все игры доступны бесплатно на GitHub, с premium-версиями для подписчиков.

## Технологии

- **Движок:** Canvas 2D (vanilla JS, no dependencies)
- **Язык:** JavaScript (ES modules)
- **Платформы:** Web (все браузеры), Mobile (touch controls)
- **Engine модули:** core.js, input.js, ui.js, physics.js, renderer.js, audio.js
- **Платформы:** Web (все браузеры), Mobile (PWA)

## Установка

```bash
git clone https://github.com/algocosmos/algocosmos-games.git
cd algocosmos-games
npm install
npm run dev
```
